# Constitución del proyecto
1. **Costo cero**: solo plan Spark de Firebase, CDN gratuitos y GitHub gratis. Nada que exija tarjeta.
2. **Simplicidad**: HTML + JS vanilla, sin bundler ni framework. Debe correr con `python3 server.py`.
3. **Privacidad por diseño**: el precio de inversión nunca es legible públicamente.
4. **Probable**: la lógica de negocio vive en módulos puros con pruebas unitarias.
5. **Accesible y móvil primero**: foco visible, contraste, `prefers-reduced-motion`, responsive.
6. **Especificación primero**: ningún cambio de comportamiento sin spec y criterios de aceptación.
